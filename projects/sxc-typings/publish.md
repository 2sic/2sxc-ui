# Publish and Generate Documentation

This readme is called `publish.md` so it's not listed in npm on home.

We're explaining how to do 2 things

1. Create the `@2sic/sxc-typings` package for NPM
1. Generate the documentation for 2sic-docs package to import

## 1. How to publish the Types @2sic/sxc-typings to NPM

1. First generate the latest typings, by running the `npm run generate` - this will run `typings.cmd`
    1. This will also trim the latest typings (hide `@internal`), by running the `api-extractor` npm script  
1. Then update the version number in this package here
1. probably do some dry-runs or beta releases
1. Then finally publish

## WIP Instructions

* `npm install -g @microsoft/api-documenter`
* <https://api-extractor.com/pages/setup/generating_docs/>

### How it Works

Basically there are a few things necessary to work

1. The `typings.cmd` will clean the target `parts/dist` folder (temp folder, not in git versioning)
1. Then it will call `tsc` to generate the typings into the `parts/dist` folder  
   To make it work, there is a `tsconfig.json` in this folder, which expands on the main `../inpage/tsconfig.json`
1. Then it will call the `api-extractor`
    1. ...which will check the `api-extractor.json` to load the `api-extractor-index.d.ts` to generate the final API report and trimmed typings.
    1. The result will be stored in the `/index-public.d.ts` in the root folder.
1. Then it will copy the final files removing the `.d` extension for docfx to work to `/docs-public.ts` in the root

### Result

#### npm Package

The final npm package will need

1. the `index.d.ts` which is manually built, and imports the `index-public` from the root folder
1. the `index-public.d.ts` which is generated by the `api-extractor` and contains the trimmed typings.
1. the `readme.md` which will be included in the distribution
1. the `package.json` which contains the information, especially the reference to the main `index.d.ts` file + the list of files (just the ts, readme etc. are auto-included)
1. the `LICENSE` file (MIT)

You can now run `npm run publish-dry` to dry-run what would happen if you publish.
Or run `npm run publish-beta` to publish a beta version.
Or run `npm run publish-prod` to publish the final production version.

### Dependencies

Because some old APIs still have some jQuery in it, we need to have these imported into this project so the build works.
